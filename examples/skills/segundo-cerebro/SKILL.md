# Segundo cérebro

O vault em `/caminho/do/vault` é a fonte da verdade operacional.
Não invente convenções: leia e aplique. Spec do kit: README do repositório `segundo-cerebro-operacional`.

## Ao retomar

Ler estado-atual, últimos 2–3 diários, prioridades.
Responder: 1 projeto, até 3 tarefas, o que não abrir.
Não inventar roadmap; priorizar continuidade a partir de *Onde paramos*.

## Ao registrar / fechar

Diário do dia + edição cirúrgica do estado-atual.
Decisão importante → `15-decisoes/` (nota + índice).
Conta → `pendencias.md` canônico (não deixar ação nova só no diário ou no briefing).

Default: gravar e resumir em 2–3 linhas. Override: "só me mostre o bloco para colar".

## Granularidade

Item simples → nota única. Item rico → pasta com `visao.md` + satélites só os que tiverem conteúdo. Nunca pasta vazia.

## Nunca

- Segredos no Markdown (usar `[removido]`)
- Colar chat inteiro
- Reescrever nota curada inteira
- Promover incubado sem olhar prioridades
- Reorganizar o vault no meio de um chat de execução
