# Claude (Claude Code, Claude.ai Projects)

Contrato: [AGENTS.md](../AGENTS.md). Bootstrap: [bootstrap.md](bootstrap.md).

## Claude Code

1. Coloque [AGENTS.md](../AGENTS.md) na raiz do *vault* (ou um `CLAUDE.md` com o mesmo contrato e o path absoluto do vault).
2. Copie [templates/vault-minimo](../templates/vault-minimo) para a pasta do vault.
3. Cole [bootstrap.md](bootstrap.md) na primeira sessão, com a mesa real.

Não cole o README inteiro em always-on. O contrato curto + o pacote mínimo (estado-atual, diários, prioridades) bastam.

## Claude.ai Project

Instruções do projeto = texto de `AGENTS.md` (path do vault se houver conector de arquivos). Sem disco, o Claude devolve Markdown para a pessoa gravar. Extraia; não peça para despejar o chat no vault.
