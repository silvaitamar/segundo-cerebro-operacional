# ChatGPT (Custom GPT, Projects)

Contrato: [AGENTS.md](../AGENTS.md). Bootstrap: [bootstrap.md](bootstrap.md).

O ChatGPT **não** grava o vault no disco sozinho. O segundo cérebro continua sendo arquivos Markdown *seus*.

## Project / GPT

1. Cole o contrato de `AGENTS.md` em Instructions (curto; não o README inteiro).
2. Anexe, a cada sessão, o pacote mínimo: estado-atual, 2–3 diários, prioridades.
3. Peça extração (diário + estado-atual cirúrgico), não o transcript.
4. Grave os blocos que ele devolver nos arquivos locais.

Memória da conta OpenAI **não** substitui o vault: ela some ou mistura contexto. O Markdown é a fonte da verdade.

## Primeira estrutura

Use o prompt de [bootstrap.md](bootstrap.md) e peça os arquivos prontos para salvar em `/caminho/do/vault/`. Depois abra essa pasta no Obsidian, no Cursor, ou só no editor.
